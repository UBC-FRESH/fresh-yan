# Records reproducibility

All records under `results/` are regenerated by tracked commands (run from the
repository root). Every record carries `fy_commit`, `fy_version`, `ws3_version`, and
`libcbm_version` provenance columns (plus `tsa` where relevant).

## Layout

- **Legacy TSA 24 records** (legacy Woodstock sections): `results/no_harvest/`,
  `results/base_scenario/`, `results/tradeoff_grid/`, `results/robustness/`; legacy
  curves in `curves/c_curves_{p,f}.pkl`.
- **Five-TSA campaign records** (femic instances; model spec p113_5): per unit
  `results/femic-tsa<code>/{no_harvest,base_scenario,tradeoff_grid}/`, curves in
  `curves/femic-tsa<code>/`; cross-unit analysis and derived records in
  `results/cross-tsa/`. Instance pins: see `planning/multi-tsa-extension.md`.

## Five-TSA campaign (the manuscript's experiment)

Common section arguments: `--section-units periods --harvest-acode cc`. The instance
ws3 sections live at `<instances-root>/femic-tsa<code>-instance/output/ws3` (the
`femic` workspace `external/` directory).

```bash
# 1. Carbon yield curves (per unit; rotation age 120, cycle mode)
fresh-yan generate-curves --tsa tsa24 \
  --model-path <instances-root>/femic-tsa24-instance/output/ws3 \
  --section-units periods --harvest-acode cc \
  --out-dir curves/femic-tsa24 --rotation-age 120 --n-steps 700

# 2. No-harvest validation (five units)
fresh-yan no-harvest --tsa tsa24 \
  --model-path <instances-root>/femic-tsa24-instance/output/ws3 \
  --section-units periods --harvest-acode cc \
  --curves-dir curves/femic-tsa24 --out-dir results/femic-tsa24/no_harvest

# 3. Base scenarios (five units)
fresh-yan base-scenario --tsa tsa24 \
  --model-path <instances-root>/femic-tsa24-instance/output/ws3 \
  --section-units periods --harvest-acode cc \
  --curves-dir curves/femic-tsa24 --out-dir results/femic-tsa24/base_scenario

# 4. Emission-minimizing grids (25 displacement x 200 half-life design)
fresh-yan trade-off-grid --tsa tsa24 \
  --model-path <instances-root>/femic-tsa24-instance/output/ws3 \
  --section-units periods --harvest-acode cc \
  --curves-dir curves/femic-tsa24 --out-dir results/femic-tsa24/tradeoff_grid \
  --workers 14 --solver highs

# 5. Cross-TSA analysis + derived records and figures
python scripts/cross_tsa_analysis.py --labels femic-tsa08 femic-tsa16 femic-tsa24 \
  femic-tsa40 femic-tsa41 --out-dir results/cross-tsa
python scripts/reset_residuals.py --tsa 24 --out-dir results/cross-tsa
python scripts/five_tsa_figures.py --instances-root <instances-root> \
  --out-dir results/cross-tsa/figures
python scripts/analyze_sensitivity.py \
  --summary results/femic-tsa24/tradeoff_grid/tradeoff_grid_summary.csv \
  --out-dir results/femic-tsa24/tradeoff_grid/figures
```

Design and validation (verified 2026-10-13 by an independent audit, including
end-to-end re-solves of four committed cells: exact harvest totals, net emission
agreement to <=6e-8 tCO2 on ~1e9 tCO2):

- 5,000 unique (half-life, displacement) cells per unit; no NaNs; no cell harvest
  exceeds its unit's base scenario; 5% even-flow holds in every cell.
- Flip characterization at a 100-year half-life (df50): 0.95 / 1.56 / 1.61 / 1.35 /
  1.54 tC/tC for TSA 08/16/24/40/41; grid maxima 0.57-0.78 of base; TSA 16 has 1,446
  zero-harvest cells (displacement <= ~0.5).
- No-harvest validation (ws3 curves vs direct libCBM): period-mean absolute stock
  differences of 0.9-3.7% (ecosystem), 1.4-3.8% (biomass), 0.9-6.2% (DOM).
- Base scenarios: TSA 24 harvests 326,188-360,523 ha/period and 6.73-7.44 x 10^7
  m3/period (1.41 x 10^9 m3 total); growing stock 3.65 -> 1.95 x 10^8 m3. The five
  units total 0.28-1.41 x 10^9 m3. The units table's period-0 inventory carbon is
  recorded in `results/cross-tsa/five_tsa_attributes.csv`.
- Accounting invariants (corrected v2): end-of-period stock-difference ecosystem term;
  products-only HWP ledger (inflow = curve merchantable carbon x 0.85, split 50/50
  paper/solid; survival = 2**(-10/half-life)); substitution = displacement x solid
  inflow. The LP objective equals the negative of the reported tracker total, and the
  telescoped conservation identity closes to solver precision
  (`tests/test_accounting.py`).
- Reset residuals of the generated curves: see `results/cross-tsa/reset_residuals_tsa*.csv`
  (documented cycle metric and the direct cut residual per development type, with the
  base-scenario harvested area for the net phantom-carbon bound).

## Legacy TSA 24 records

Managed legacy curves are generated by simulating the clearcut (rotation age 120,
cycle mode): `fresh-yan generate-curves --rotation-age 120` (defaults: legacy
sections). The no-harvest comparison is `fresh-yan no-harvest`; the base scenario
`fresh-yan base-scenario --solver highs` reproduces the legacy ranges (harvest area
368,874-407,702 ha/period; harvest volume 7.45-8.24 x 10^7 m3/period; these are the
LEGACY model's numbers, not the manuscript's - the manuscript reports the femic
instance values above). The legacy trade-off grid is
`fresh-yan trade-off-grid --workers 48`; its published experiments used the
pre-correction flux-based accounting on spun-up curves by design (see
`planning/curve-generation-and-reset-findings.md` for the corrected behavior and the
audit record). Legacy validation: 5,000 rows, 25 x 200 unique, no NaN/inf; LP objective
== -(tracker total) spot cells exact (hl=100/df=1.5: 530,250,376.82 m3 utilized
volume, -1,586,066,278.9708 tCO2); worst net reset residual -20.19 MtC (1.63% of
landscape C). One-at-a-time structural robustness spot-checks (legacy TSA 24):
`python scripts/robustness_checks.py --out-dir results/robustness`.
