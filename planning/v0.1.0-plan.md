# fresh-yan v0.1.0 plan

Goal: an open, reproducible code + data + results package behind the CJFR manuscript, in
the style of `UBC-FRESH/fresh-daugherty`: tracked records regenerated by tracked
commands, per-record provenance, curated supplementary material, tests, CI, and a Zenodo
DOI.

## Provenance model

Every record carries `fy_commit`, `fy_version`, `ws3_version`, and `libcbm_version`
(`src/fresh_yan/records.py`; checked by `tests/test_records.py`).

## Phases

- **P1 — Scaffold (done, 2026-10-11).** Repository, package, CLI (`fresh-yan no-harvest`),
  CI, inputs (`data/`, `curves/`).
- **P2 — Records: no-harvest + base scenario.**
  - No-harvest comparison: done (`results/no_harvest/`); reproduces the legacy committed
    outputs exactly, with provenance columns added.
  - Base scenario: maximize even-flow harvest volume over the horizon; records are
    per-period harvest area, harvest volume, and growing stock (`fresh-yan base-scenario`).
    Requires the notebook's `fm.actions['harvest'].is_harvest = True` and a solver
    (Gurobi or HiGHS; verified to agree to ~1e-7).
- **P3 — Records: trade-off grid.** Refactor the legacy `minimize_emission` loop into a
  CLI command: bi-objective frontiers per (half-life, displacement) pair; writes
  per-scenario harvest/stock/emission records. Heavy compute; parallelizable
  (`--workers`).
- **P4 — Records: sensitivity grid.** Optimal harvest volume over the (half-life,
  displacement) plane — inputs to the manuscript's 3D and orthographic figures — built
  from P3 records.
- **P5 — Supplementary + manuscript builders.** `scripts/build_supplement.py` (curated
  pages and figures), figure/table builders mapping every manuscript figure/table to
  tracked records, and `planning/manuscript-handoff.md` mapping every manuscript number
  to a source.
- **P6 — Release.** `v0.1.0` tag, Zenodo deposit, and the manuscript's software/data
  availability statement.

## Environment

Validated 2026-10-11: Python 3.12.3; ws3 `a267f02` (git pin; includes the `to_cbm_sit`
fix, UBC-FRESH/ws3#155); libcbm 2.10.2; numpy 2.5.4; pandas 3.0.6; scipy 1.18.1;
matplotlib 3.11.2. Solvers: HiGHS 1.15.1 (open) and Gurobi 13.0.3 (optional extra).
